# 2.15.2

- Producer review no longer loops on a fenced reply. The review model often returns its decision wrapped in a
  markdown code fence (```json ... ```). The Producer parsed the raw reply, so every review of a delivered ticket
  threw a JSON error, failed the whole attention review and was retried every few minutes without ever submitting
  the decision. VGF943299B17-5 (Technical Architecture) sat in Producer Review, approved by the model on every run.
- Model replies for delivery acceptance and scope amendment are now unwrapped from code fences (and surrounding
  prose) before parsing.
- A reply that still cannot be read is reported on the ticket as "Producer acceptance is waiting: ..." instead of
  failing the attention review, so the stall is visible.
- No new capabilities or grants.
