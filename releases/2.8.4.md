# 2.8.4

## Model-aligned token budgets

- Remove fixed agent-level maximums from the configurable context-window and output-token budgets so users can match the selected model and provider.
- Preserve minimum budgets and existing output-below-context validation where declared; the provider profile remains the authoritative execution ceiling.
- Accept a complete production-brief JSON object even when a model appends fenced or reasoning text after it; malformed or incomplete objects still fail validation.
