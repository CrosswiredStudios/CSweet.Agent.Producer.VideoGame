# 4.0.7

Scope amendment directions are retained while other assignments are running, rather than refused and forgotten. Work-state events and bounded attention/reconnect recovery wake the saved amendment at the next eligible stopped boundary, without requiring the sender to repeat it.

- `DeferredScopeAmendment` binds the saved request to its authenticated requester, exact conversation/message/turn, project/team board, sprint execution, stage and planning revisions. Capture uses optimistic concurrency, and one outstanding request cannot be silently overwritten by another.
- A durable personal commitment waits for active writers to stop. Boundary events can wake that exact wait early; the existing scheduled wait provides missed-event recovery. A saved request repairs an interrupted agenda creation on reconnect.
- The Producer rechecks the current reporting chain, source message, board ownership, planning revisions and execution before preparing exact replacements. Changed scope, revoked access or stale authority retains the direction for review instead of applying it. The existing corrected-planning and sprint cancellation/carryover guards still own application.
- Duplicate deliveries and interrupted handoffs reuse the exact saved planning request and commitment. Queuing corrected planning never claims that the amendment has finished, a measurement ran, or QA passed.
- A bounded, one-time upgrade recovery recognizes the old Producer's exact refusal paired with the original supervisor's command and matching conversation turn. It ignores quoted commands, spoofed replies, later superseding directions, inactive authority and changed execution boundaries. Discovery covers the 32 most recently updated direct conversations and their latest 200 returned messages.

Verification: 415 tests pass with sibling SDK/contract references disabled. The installed package must be upgraded through the published release and Installed Agents flow. No new grants, schema migration, direct database mutation or installed-payload patch is required.
