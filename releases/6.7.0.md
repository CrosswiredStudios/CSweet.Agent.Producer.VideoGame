# 6.7.0

From Super Awesome Games ticket VGD2A04892DB-34 (2026-11-12).

## Interaction criteria reach the ticket

When a Technical Director proposal names `interactionCriteria` (video-game contracts 1.2.0), the ticket's
`Verifications` gain a `browser-interaction` requirement for exactly those criteria (WorkManagement contracts 5.5.0),
next to the browser smoke. QA 5.7.0 requires live interaction evidence for those criteria only. Indexes outside the
proposal's criteria, duplicates, and interaction on a task without a browser build are dropped. Proposals without the
field produce the same verifications as before.

## Agent defects are not offered as a plain retry

A Blocked outcome carrying `agent-defect:v1` means the assigned agent failed in its own processing, not on the work.
The Producer now raises it once per attempt as needing an agent update or investigation, with the agent's exact reason,
instead of the generic "none of my recovery steps apply … reply Retry" message. On ticket 34 the owner was offered
Retry for a failure the retry would have reproduced. `DecisionRequiredDiagnostic` now comes from
`WorkExecutionDiagnostics.DecisionRequired` (same value).

Depends on WorkManagement contracts 5.5.0 and video-game contracts 1.2.0 (publish first). SDK unchanged (5.23.1).

Validation: `dotnet test` 528 passed, 0 failed, against the local WorkManagement contracts checkout and locally packed
video-game contracts 1.2.0. Not yet run live.
