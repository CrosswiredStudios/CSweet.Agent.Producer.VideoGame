# 2.17.0

- Adds durable ticket discussion notifications and directed replies using the shared discussion protocol. Explicit `@Full Name:` questions request a response; informational notifications do not create reply loops.
- Resumes a blocked discussion wait only after the requested installation replies to the exact question revision, retaining assignment revision checks and attempt budgets. Reply text never grants approval or changes acceptance criteria.
- Rereads current authorized state, ignores stale/deleted requests, deduplicates replies and discovers missed questions during bounded attention recovery.
- Requires the C-Sweet ticket discussion host update and approval of the new event subscription/read capabilities.
