# 6.4.3

Fixes a stall seen at Super Awesome Games on 2026-11-10. After the project was approved, every Producer attention review failed with "The project delivery grant is required: work.delivery.read.v1" and its event was dead-lettered (four times in four minutes).

Cause: `HandleAttentionReviewAsync` runs `ReconcileDeliveryCorrectionAsync` for each project the Producer is accountable for before it reaches board creation. The Producer's project delivery grant is added by the platform only when the project board is created (`ProjectSetupService.ReconcileProjectBoardAccessAsync`). Until then the plan read is denied, the exception failed the whole review, and the review never reached the step that creates the board.

- `ReconcileDeliveryCorrectionAsync` now treats a `Denied` result from `work.delivery.read.v1` as nothing to reconcile. Other failures still propagate. `HandleManagerRecoveryAsync` gets the same behavior.

No new permissions. No platform change required.

Validation: not yet run. Written without a .NET SDK available; run `dotnet test` and the published output's `--self-test` before publishing. No regression test was added.
