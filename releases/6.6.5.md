# 6.6.5

Moves to `CSweet.Agent.SDK` 5.23.1 (was 5.23.0). No agent code changed. No manifest, capability, grant or configuration
change.

The Producer's manager acceptance of an increment uses the same aggregate review as the Technical Director's technical
review. On 2026-11-12 at QFN Games that review rejected an increment whose every criterion was approved, because notes
from the bounded source inspections of a large candidate were appended to the verdict as findings.

With SDK 5.23.1, inspection defects are ruled on against the whole candidate (a genuine or uncertain one blocks, a
dismissal keeps its reason in `sourceInspectionRulings`), notes never reject, and a rejection's summary starts with
"Changes requested (N blocking findings): …". Correction planning therefore receives only findings a reviewer
confirmed.

Tests: 526/526 pass against SDK 5.23.1.
